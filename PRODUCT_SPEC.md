# Product Specification

## Product

Bearing is a category-first, agent-first marketplace for live BNB Smart Chain agents.

## Promise

Find the right onchain agent. Understand it quickly. Hire it safely.

## Primary user

An active BNB Chain DeFi user who needs monitoring or automation but cannot confidently evaluate which agent is live, capable, safe, or worth paying for.

## Core workflow

`Choose job category → Search/filter agents → Inspect evidence → Compare → Run bounded test → Connect wallet when required → Hire → Track execution → Verify result and payment`

## Required category workspaces

- Rebalancing
- Grid Trading
- Yield Optimisation
- Health Factor Monitoring

Each workspace explains the job, risks, supported inputs, live context, available agent supply, qualification requirements, and execution path. It must remain useful when no verified agent is listed.

## Trust requirements

Listings must expose identity, capability, live status, evidence provenance, recent execution, permissions, cost, expected result, and failure behavior. Claims must be labelled as live onchain, live external API, marketplace-observed, fixture-backed test data, or self-reported.

## Scope

MVP includes real live agents, real BNB data, real execution records, a non-custodial hiring flow, real testnet settlement, and public access. The flagship PancakeSwap rebalancer is the first supply item. The other categories use verified live integrations.

## Non-goals

No agent portfolio presented as a marketplace, unrestricted custody, fake performance, public mock execution, mainnet trading with real user funds, task bidding, or multi-chain expansion in the first release.

## Acceptance

A new user can enter without blockchain knowledge, select a job, understand an agent, compare alternatives, see permissions and cost, reach approval, and inspect a truthful execution result without outside instructions.
