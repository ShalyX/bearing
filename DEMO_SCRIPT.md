# Demo Script Plan

## Demo promise

Find the right onchain agent. Understand it quickly. Hire it safely.

## Live path

1. Enter Bearing without connecting a wallet.
2. Choose Rebalancing.
3. Read the plain-language job and current constraints.
4. Select a live PancakeSwap liquidity position.
5. Compare verified agents using real evidence.
6. Inspect permissions, cost, slippage, and expected result.
7. Approve a bounded real testnet rebalance after the security gate has passed.
8. Show the submitted and confirmed transaction.
9. Read the resulting position.
10. Show the before/after state, execution trace, cost, and proof link.
11. Briefly visit the other three category workspaces and show their real agent supply and evidence states.

## Rules

- No mock agent presented as live.
- No fixture-backed execution shown as product proof.
- Testnet status is stated plainly.
- Every visible action must work or be removed.
- If a live integration is unavailable, the category is marked unavailable rather than simulated.
