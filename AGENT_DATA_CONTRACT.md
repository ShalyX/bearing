# Agent Data Contract

Every agent listing must provide:

- Stable identifier
- ERC-8004 identity or verifiable live endpoint
- Owner/source and execution ownership
- One required category
- Plain-language capability description
- Supported protocols and inputs
- Live status and last-seen time
- Required permissions
- Spend, slippage, and execution limits
- Price and expected duration
- Test availability
- Recent execution evidence
- Failure and cancellation behavior
- Evidence provenance label

An agent is not listable until the endpoint, identity, invocation path, result, and category-specific evidence have been verified.
